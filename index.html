🧑 人間向け — 手動実行（無料）

ブラウザだけで完結します。支払い不要です。

  1. 上のフォームでキーワード / テンプレート / Noise を設定し、最新で検索 または 話題で検索 を押す。
  2. X の結果から有用な投稿をコピーし、下の Collected signals に 1行1投稿 で貼る。
  3. Product / Target area を埋め、Handoff 生成 → Signal-to-Fix 用をコピー を押す。
  4. Signal-to-Fix を開く を押し、Product 欄と Feedback 欄に貼り付けて Analyze Feedback。
  5. 結果の keep だけを使う。reduce / discard は実装に入れない。Copy Codex Prompt で 1 つの小さい改善を依頼する。

🤖 AI Agent 向け — 自動連携

本番の検索 URL 自動利用は x402（$0.01）が必要です。計画・スコア・handoff は無料。

  1. 読む: signal-to-fix-pipeline.json + agent-use.json
  2. 呼ぶ: buildSignalToFixPipeline({ productName, intent? })
  3. scoreQuery → x402 pay → searchUrl で投稿収集
  4. buildHandoffPackage / pipeline + feedback → Signal-to-Fix
  5. 下流は decision === "keep" のみ

HyperXosistAgent.buildSignalToFixPipeline({ productName: 'Acme', feedback: ['...'] })
